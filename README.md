# bongjuncha.github.io

차봉준 개인 사이트. 지금은 한 페이지(index.html), 2027년 1월에 Work / Writing 추가 예정.

## 구조
- `index.html` — 전부 이 파일 하나. 스타일·내용 모두 안에 있음.
- 외부 라이브러리 없음. 그냥 열면 됨.

## 수정하는 법
1. `index.html`을 텍스트 에디터(또는 Antigravity)로 연다.
2. 문장을 고친다. `<script type="application/ld+json">` 안의 내용은 AI용 명함이라 본문과 같은 사실을 유지할 것.
3. 저장 → GitHub Desktop에서 Commit → Push. 1~2분 뒤 사이트에 반영.

## 1월에 할 일
- Work 페이지: 프로젝트별 폴더 `work/<slug>/index.html`
- Writing 페이지: `writing/<slug>/index.html`
- 도메인 연결: 저장소 Settings → Pages → Custom domain
